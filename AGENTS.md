# Instructions for Anno 117: Pax Romana mod work

- This repository contains Anno 117 mods. Start with [Documentation](Documentation/README.md), [coverage](Documentation/reference/coverage.md) and [discrepancies](Documentation/reference/discrepancies.md), then read the relevant chapters. Answer in the user's language; repository documentation is English.
- **Before any game-dependent proposal, implementation decision, change or dependent test, complete the [feature-specific audit](Documentation/foundations/vanilla-research.md) against current Anno 117 Vanilla sources.** An index, old extract, changelog or working mod does not replace that audit. Ask for inaccessible essential sources. Resolve machine-specific paths through ignored `Documentation/local.json`.
- Keep fixes targeted. Preserve names, structure, comments and the encoding of existing files. Ask before a broad rewrite or encoding change. Use UTF-8 and CRLF for new text in the Windows workspace; honor Git's text normalization.
- Follow 117-specific loader rules. Use current native target paths, Anno 117 metadata and the 117 GUID registry. For ports, use the [1800 comparison](Documentation/reference/anno-1800-comparison.md) and confirm the specific target, schema, defaults and consumers in current 117 Vanilla. Treat 1800 gameplay data, GUIDs, Lua APIs and save behavior as unverified in 117. Reconcile actual files, not only mod names, before changing a bundled dependency or a variant with the same ModID.
- Run Git and Lua/Luau outside the Windows sandbox via the supported permission route. Check PowerShell quoting and pipelines; collect statement-based `foreach` results before piping. Never repurpose `HOME` or `CODEX_HOME`. If the WindowsApps PowerShell shim fails at process start with CreateProcessAsUserW error 5, retry the unchanged safe command once with escalation; if it still fails, ask how to proceed.
- If a supplied literal path with backslash-underscore does not exist, also check the plain underscore variant and disclose a confirmed correction. Ask when intent is unclear or materially different remedies require a decision. Keep necessary questions pending without a timeout.
- Keep development, offline checks, installation and publication separate. Do not change a live mod profile, overwrite installed mods, commit, push, upload or message anyone without authorization. Repository availability does not grant reuse or redistribution permission.
- Report source evidence, structural checks, offline evaluator results, game/save checks and multiplayer observations separately. Update the one maintained knowledge base via [maintenance](Documentation/maintenance.md). Keep Vanilla files, private configuration, saves and disposable output out of Git.
