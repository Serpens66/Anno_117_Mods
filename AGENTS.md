# Instructions for Anno 117: Pax Romana mod work

- This repository contains Anno 117 mods. Start with [Documentation](Documentation/README.md), [coverage](Documentation/reference/coverage.md) and [discrepancies](Documentation/reference/discrepancies.md), then read the relevant chapters. Answer in the user's language; repository documentation is English.
- Subagents are explicitly permitted for chats in this project. Use them whenever you judge delegation or parallel agent work useful for the task, without asking for additional permission.
- **Before any game-dependent proposal, implementation decision, change or dependent test, complete the [feature-specific audit](Documentation/foundations/vanilla-research.md) against current Anno 117 Vanilla sources.** An index, old extract, changelog or working mod does not replace that audit. Ask for inaccessible essential sources. With filesystem access, read ignored `Documentation/local.json` first and resolve every relative path against its directory. Empty fields are unset. Follow the [setup](Documentation/setup.md) if it is missing. Use configured sources, repository files and the [public source register](Documentation/reference/sources.md), checking their versions and accessibility. Chats without filesystem access need the relevant documents and feature files supplied by the user.
- Keep fixes targeted. Preserve names, structure, comments and the encoding of existing files. Ask before a broad rewrite or encoding change. Use UTF-8 and CRLF for new text in the Windows workspace; honor Git's text normalization.
- Format XML with one element per line and consistent indentation. Keep a leaf value as `<Tag>value</Tag>` on one line, but put parent/container opening tags, child elements and closing tags on separate lines. Do not compress multiple elements into a single line. Preserve multiline text values and comments when reformatting.
- Serp's reserved inclusive GUID range is **1500000000-1500010000**. This register describes ownership in this repository. Other authors adapting the documentation must use their own authorized allocations. Before allocating IDs, read [the maintained allocation register](Documentation/reference/guid-allocations.md) and run `python Documentation/tools/inventory_guid_allocations.py --check`. Reserve new allocations there and refresh it with `--write` after edits. The block **1500001200-1500001299** belongs exclusively to `cheat-keybinds-serp`, including its unused gaps. Check all workspace packages and distinguish definitions, references, text IDs and same-ModID variants. Do not introduce cross-owner reuse or silently renumber existing published IDs; document historical conflicts explicitly.
- Follow 117-specific loader rules. Use current native target paths, Anno 117 metadata and the 117 GUID registry. For ports, use the [1800 comparison](Documentation/reference/anno-1800-comparison.md) and confirm the specific target, schema, defaults and consumers in current 117 Vanilla. Treat 1800 gameplay data, GUIDs, Lua APIs and save behavior as unverified in 117. Reconcile actual files, not only mod names, before changing a bundled dependency or a variant with the same ModID.
- In the managed Windows environment, run Git and Lua/Luau outside the Windows sandbox via the supported permission route. On other hosts, follow that environment's permission and execution model. Check PowerShell quoting and pipelines; collect statement-based `foreach` results before piping. Never repurpose `HOME` or `CODEX_HOME`. If the WindowsApps PowerShell shim fails at process start with CreateProcessAsUserW error 5, retry the unchanged safe command once with escalation; if it still fails, ask how to proceed.
- If a supplied literal path with backslash-underscore does not exist, also check the plain underscore variant and disclose a confirmed correction. Ask when intent is unclear or materially different remedies require a decision. Keep necessary questions pending without a timeout.
- Keep development, offline checks, installation and publication separate. Do not change a live mod profile, overwrite installed mods, commit, push, upload or message anyone without authorization. Repository availability does not grant reuse or redistribution permission.
- Report source evidence, structural checks, offline evaluator results, game/save checks and multiplayer observations separately. Update the one maintained knowledge base via [maintenance](Documentation/maintenance.md). Keep Vanilla files, private configuration, saves and disposable output out of Git.
