# Public changes and their implications for mods

Scope: official PC-relevant game notes and identifiable public modding/tool changes through 2026-11-10. This is a review index for mod work, not a reproduction of patch notes. Platform/build uploads can exist without a public changelog. Dates below are release dates unless stated otherwise.

| Release | Relevant changes and what to recheck |
| --- | --- |
| [Launch](https://www.anno-union.com/anno-117-pax-romana-its-launch-day/), 2025-11-13 | Integrated PC loader and manual installation workflow were documented in the [mod support devblog](https://www.anno-union.com/devblog-what-about-mod-support/) and [PC modding FAQ](https://www.anno-union.com/modding-in-anno-117-pax-romana/). The public 117 changes reference supersedes demo-era setup notes. No standalone official 1.1/1.2 notes were found. |
| [1.3](https://www.anno-union.com/updates/anno-117-pax-romana-patch-1-3/), 2025-12-16 | Map-generation changes affect new maps and reproduction by seed. Fixes to religion, quests, gameplay and desyncs can change the baseline for early mods. Do not use a pre-update seed or save as proof of current generation. |
| Snow hotfix, 2025-12-25 | Publisher notice is preserved in the [Steam news mirror](https://steamdb.info/patchnotes/21310925/): PC snow effect disabled. No loader change claimed. |

Notes also describe aquatic construction and DLC ownership issues. Recheck workarounds and distinguish patch behavior from saved data. |
| [1.4.1](https://www.anno-union.com/updates/anno-117-pax-romana-patch-1-4-1/), 2026-03-05 | Follow-up fixes include aqueduct construction, DLC-wall multiplayer desync and console raytracing. Recheck 1.4's known issues before retaining workarounds. |
| [1.5](https://www.anno-union.com/updates/anno-117-pax-romana-patch-1-5/), 2026-04-30 | Prophecies of Ash introduces Cinis and volcano quests. Vassalization, late rejoin and save compatibility fixes. Do not infer arbitrary island edits are save-compatible. |

Hippodrome DLC, heroic specialists, notes and replace mode also land here. Recheck bread, island-wide monument effects, specialist targets and DLC gates. |
| [2.1](https://www.anno-union.com/updates/anno-117-pax-romana-patch-2-1/), 2026-09-17 | Echoes of Kassandra; adjusts Laevinus, Kirjokansi and Tiranna and changes tooltip/monument and DLC unlock behavior. Relevant specialist/effect patches should target the current data. |
| [3.0](https://www.anno-union.com/updates/anno-117-pax-romana-patch-3-0/), 2026-11-05 | Dawn of the Delta, stamps, new storage and specialists statistics, quest/UI and balancing changes. **Mod mismatch UI now names differences, pause UI marks modded games, and MP also checks sub-mods.** Recompare parent and nested packages on each peer. Changes to consumption, diplomacy, attributes, trading and province content merit fresh native audits. |

The [2026 roadmap](https://www.anno-union.com/roadmap-for-2026/) moves the integrated mod browser/manager from late 2026 to the following year. That is a plan. It does not negate manual PC mod support, and it is separate from 3.0's mod indicators.

## Mod, loader and tool history

- The local repository contains 16 commits from 2025-09-02 through 2026-06-03 and no local tags. Initial commits introduced zoom and demo packages; November converted selected features toward 117 paths and added the shared construction-pool updates; January added the two DDS mods; February revised the script probe; March/April split Recommended Cheat Keybinds from its WIP variant and revised multiplayer speed; June updated speed metadata. See [workspace findings](workspace.md) for package-level changelog implications and [inventory](workspace-inventory.json) for metadata entries and text changelogs. GitHub's releases/commits pages did not resolve in the public fetch; this history is from the local checkout.
- Public mod.io URLs surfaced for [Change Gamespeed Multiplayer](https://mod.io/g/anno-117-pax-romana/m/change-gamespeed-multiplayer) and [Unlock All Buildings](https://mod.io/g/anno-117-pax-romana/m/unlock-all-buildings). A public title alone does not identify an author/file or prove parity. The fetched GameSpeed page did not expose version history; rely on the repo entries for local versions and verify the live release when relevant.

The older local `modloader-changes.md` outside the repo is historical pre-release context. Check current documentation rather than copying its syntax wholesale.
